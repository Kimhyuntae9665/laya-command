# Components and attribution

This repository contains skill instructions and helper code prepared with Codex
under the repository owner's direction and review. It does not claim independent
model training or production deployment. Repository code is MIT-licensed.

Model weights and third-party executables are downloaded separately and are not
included in this repository. Their licenses remain independent of this code:

- [Qwen3-4B-Instruct-2507](https://huggingface.co/Qwen/Qwen3-4B-Instruct-2507): Qwen, Apache-2.0.
- [Q4_K_M GGUF](https://huggingface.co/unsloth/Qwen3-4B-Instruct-2507-GGUF): quantized distribution by Unsloth.
- [Laya](https://github.com/NandhaKishorM/laya) and [English checkpoint](https://huggingface.co/convaiinnovations/laya): Convai Innovations / upstream authors, Apache-2.0.
- [llama.cpp](https://github.com/ggml-org/llama.cpp): upstream contributors, MIT.
- PyTorch, Transformers and other installed packages retain their own licenses.

Upstream model benchmark claims do not describe this repository's end-to-end
performance. See the README and committed local benchmark results.
